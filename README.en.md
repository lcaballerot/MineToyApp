## What is MineToy?

One app with everything on the MineToy website: the store, voting, the ranking and your profile. It also brings
**proximity voice chat** that keeps working while Minecraft Bedrock is open on the same phone, which a browser can't do.

To link it, scan the `/vc` QR code in the game or type the code.

## What it will do

| | Feature | In a nutshell |
|---|---|---|
| 🎙️ | Proximity voice chat | Hear whoever is near you in the game, with the app in the background |
| 🛒 | Store | The website's store, paid with Apple or Google |
| 🗳️ | Vote | Daily votes and their rewards |
| 📷 | Link with a QR code | Scan the `/vc` QR code or type the code |
